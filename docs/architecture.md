# Архитектура MoodMix

`index.html` и `app.html` загружают свои ES-модули. Лендинг показывает три точки входа через ссылки. Значения `start=catalog`, `start=quiz` и `demo=1` задают начальный режим приложения. После применения параметры убираются из адреса, чтобы перезагрузка продолжала текущий сценарий браузера.

`js/main.js` создаёт локальный API, диалог, тему и пользовательские сценарии. Модули сценариев получают зависимости через параметры. Они читают снимок текущего профиля, вызывают асинхронные операции и обновляют нужные элементы. Модули данных и сервисы обходятся без DOM. Циклических импортов между сценариями нет.

| Модуль | Работа |
|---|---|
| `services/local-api.js` | Профили, настройки, избранное, посещения, отзывы, дружба, чаты и приглашения |
| `services/storage.js` | Версия, нормализация, миграция и запись снимка |
| `services/catalog.js` | Нормализация карточек, поиск, фильтры, график и внешние ссылки |
| `services/recommendations.js` | Выбор вопросов, расчёт предпочтений и ранжирование |
| `components/modal.js` | Нативный диалог, фокус, Escape, переход назад |
| `theme/` | Сохранённый выбор и отрисовка сцен по событиям прокрутки и смены темы |

Тест считает взвешенное среднее ответов по шести шкалам. Для каждой категории берётся расстояние до её профиля и прибавляются баллы за явно выбранные предпочтения. Второй этап применяет признаки конкретного места, примерное время посещения и известные цены. Повторяющийся признак учитывается один раз. При равных баллах порядок определяют тип записи, наличие источника и постоянный ID. Интерфейс показывает причины, а внутренние баллы используются для сортировки.

Каталог показывает первые 24 карточки и добавляет следующие порциями. Изменение избранного обычно обновляет одну кнопку. События прокрутки и размеров объединяются в один кадр. При reduced motion фон остаётся статическим, а SVG-анимация останавливается. Сцены и шрифт лендинга загружаются отдельно от разметки приложения. Пользовательские данные выводятся через `textContent` и свойства форм.

Пользовательские тексты и аватары ограничены по размеру. Для пользовательских аватаров поддерживаются JPEG, PNG и WebP, а при загрузке изображение обрезается и сохраняется как JPEG 256 × 256. Для ссылок из карточек допускается HTTPS. Общие правила обработки ошибок записи описаны в [модели данных](data-model.md).
