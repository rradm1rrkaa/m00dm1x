# План подключения серверной части

MoodMix сейчас использует асинхронный интерфейс `createLocalApi`. При подключении сервера создайте адаптер с теми же методами и передайте его из `js/main.js`. Каталог и алгоритм подбора могут продолжить работать с теми же объектами. Сервис профилей, отзывы, дружба и чаты получат серверный адаптер. Демо может остаться отдельным локальным режимом.

## Сущности

| Сущность | Связи и ограничения |
|---|---|
| User, Profile | UUID пользователя, отдельный публичный профиль и настройки видимости |
| Session | Сеанс с датами создания, истечения и отзыва |
| Place | Постоянный ID, источник, координаты или ссылка из источника и версия сведений |
| Favorite, Visit | Владелец и место. Для избранного уникальная пара владелец–место |
| Review, Rating | Автор и место. Один актуальный отзыв и оценка каждого автора на место |
| Friendship, FriendRequest | Уникальная пара друзей, направленная заявка и статусы |
| Conversation, Message | Участники, автор, время и курсор последнего прочитанного сообщения |
| Invitation | Ссылка на сообщение и место, инициатор, получатель, статус ответа |
| UserPreferences | Тема, правила видимости и согласие на историю теста |

## Этапы

1. **Ввести API `/v1` и серверное хранилище.** Публиковать каталог с сохранением существующих ID, договориться о форматах ответов и пагинации. Начать с чтения каталога и личного избранного.
2. **Подключить настоящую авторизацию.** Пароли обрабатывает серверный провайдер идентификации или проверенная серверная реализация с солёным адаптивным хешированием. Сеансы выдаются через защищённые cookie. Нужны отзыв сессий, восстановление доступа, ограничение частоты запросов и защита операций изменения данных.
3. **Проверять права на сервере.** Профиль изменяет владелец. Переписку читают участники. Смена статуса заявки и приглашения допускается определённым участником в допустимом состоянии. Предусмотреть блокировки, жалобы, приватность и удаление зависимых данных.
4. **Ввести синхронизацию.** Записи получают UUID и версию. Для повторных запросов используются ключи идемпотентности, для изменения отзыва — проверка версии. Сообщения добавляются с уникальным ID, а доступ к содержимому в базе и журналах ограничивается. Для статусов дружбы и приглашений сервер возвращает актуальное состояние при конфликте.
5. **Переносить данные по явному согласию.** После входа можно выбрать импорт собственных избранных мест, посещений и истории с предварительным просмотром. Локальные пароли, тестовые профили, переписка и чужие отзывы остаются локальными. Неизвестные ID мест возвращаются пользователю в отчёте импорта.
