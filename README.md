# MoodMix

MoodMix подбирает места и идеи для отдыха в Астане и окрестностях. Можно открыть каталог сразу или ответить на вопросы о настроении, времени и планах. На карточках подборки видны причины рекомендации.

## Запуск

Требуется Node.js 20 или новее. Для запуска интерфейса установка пакетов не нужна.

```sh
npm start
```

Откройте [MoodMix на локальном сервере](http://127.0.0.1:4173). Страницы используют ES Modules и загружаются по HTTP. Для статического размещения опубликуйте корневые HTML-файлы и папки `css`, `js`, `assets` с сохранением структуры.

## Что попробовать

- **Гость.** Нажмите «Посмотреть каталог», найдите Ботанический сад, откройте карточку и сохраните место. Избранное и отметки посещения хранятся в браузере.
- **Подборка.** Нажмите «Подобрать место» и выберите 7 или 25 вопросов. Можно вернуться назад, изменить ответ и по желанию сохранить результат в приватной истории.
- **Демо с профилями.** Откройте демо с лендинга или через кнопку «Демо-профили». Выберите Тимура и откройте чат с Алией. Ответьте на приглашение или отправьте сообщение. Переключитесь на Алию, чтобы увидеть его в её чате. Чтобы вернуть исходные примеры, выберите «Сбросить демо-данные».
- **Оформление.** В обоих разделах доступны «Восход», «Закат», «Грусть», «Веселье» и автоматический режим. Ручная тема сохраняется. Автоматическая тема зависит от результата теста.
- **Управление данными.** Профиль позволяет редактировать имя и аватар демопрофиля, настроить видимость, скачать данные или очистить текущий профиль. Восстановленные профили прежней версии появляются в меню выбора, если обновление открыто на том же домене и в том же браузере.

## Тесты

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

В Windows PowerShell для проверки установленным Google Chrome можно запустить `$env:MOODMIX_BROWSER='chrome'; npm.cmd run test:e2e`. Тесты поднимают отдельный сервер на порту 4176. Если он занят, задайте `MOODMIX_E2E_PORT`.

Модульные тесты охватывают расчёт подборки, поиск, фильтры, миграцию, изоляцию и удаление данных. Playwright проверяет мобильный и десктопный сценарии, включая вход, тесты, каталог, фильтры, темы, чаты и клавиатуру.

## Как устроен проект

```text
index.html / app.html       Разметка страниц
css/                       Лендинг, приложение, небо и общие элементы
js/landing.js              Темы и прокрутка лендинга
js/main.js                 Запуск приложения и связь между сценариями
js/components/             Диалоги, поля, кнопки, уведомления
js/features/               Каталог, тест, выбор профиля и социальные экраны
js/services/               Каталог, рекомендации и асинхронный локальный API
js/data/                   Места, вопросы, свойства карточек и демопрофили
js/theme/                  Выбор темы, расчёт кадров, сцены космоса и пляжа
assets/fonts/              Montserrat и Marck Script с лицензиями SIL OFL
tests/                     Node.js и Playwright
docs/                      Архитектура, данные и план подключения сервера
```

- **Места.** Добавьте запись в `js/data/places.js` с новым постоянным ID. Подтверждённые сведения с URL источника и редакционные признаки добавляйте в `js/data/place-details.js`. Существующие ID используются в избранном, отзывах и приглашениях.
- **Вопросы.** Оба теста берут вопросы из `js/data/questions.js`. Индексы вопросов быстрого теста и формула находятся в `js/services/recommendations.js`. При перестановке вопросов обновите привязки ответов в алгоритме.
- **Темы и компоненты.** Палитры находятся в `css/tokens.css`, смена изображений — в `js/theme/atmosphere.js`, управление темами — в `js/theme/theme.js`. Интерфейс правится в `js/features/` и `js/components/`, оформление — в стилях соответствующей страницы.
- **MoodMix 4.0.** Страница места открывается по адресу `app.html?place=mm-057`. Архитектура, проверенные сведения, лицензии фотографий и актуальные скриншоты собраны в [отчёте MoodMix 4.0](docs/moodmix-4.md).
- **MoodMix 4.2.** Живые сцены, обои Direct, источники фотографий и снимки всех четырёх тем собраны в [отчёте MoodMix 4.2](docs/moodmix-4.2.md).
- **Демо.** Исходные вымышленные профили и их данные меняются в `js/data/demo-data.js`.

## Ограничения и дальнейшая работа

Каталог сохраняет 188 исходных записей. Для 19 карточек Астаны добавлены ссылки на источники и подтверждена часть сведений. Публикуемые часы и цены стоит перепроверять перед визитом. Для остальных записей нужны первичные источники и проверка локаций. Подробности об источниках находятся в [модели данных](docs/data-model.md).

Данные хранятся локально. Пароли для новых профилей не запрашиваются. Социальные сценарии демонстрируют работу интерфейса на вымышленных профилях. Для рекомендаций без согласия на историю действует состояние текущей вкладки.

Интерфейс использует локальный Montserrat. В приветствии временно используется Marck Script. Для публичного встраивания Pablo Co - Script нужен файл с подходящей веб-лицензией. [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat) · [Условия доступной версии Pablo Co - Script](https://www.cufonfonts.com/font/pablo-co-script)

Подробнее в [описании архитектуры](docs/architecture.md), [модели данных](docs/data-model.md) и [плане подключения сервера](docs/backend-roadmap.md).

Десктопные и мобильные снимки после редизайна собраны в [отчёте о визуальной проверке](docs/visual-qa.md).
